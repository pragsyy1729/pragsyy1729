## 🤖 Featured Projects

### [City of Agents](https://github.com/pragsyy1729/city-of-agents) · [Live Demo](https://pragsyy1729.github.io/city-of-agents/)
15 LLM-driven citizens living, working, and socializing in a simulated T‑Nagar, Chennai — a study in how autonomous agents interact under real-world constraints. Each agent has goals, memory, and 25+ tools; BFS road pathfinding on an HTML5 Canvas world. *Reached 2,800+ people on LinkedIn (51 reactions).*
`Nemotron-Super-49B` · `React` · `Zustand` · `Canvas` · `Vite`

### [Cognitive Loop Agent](https://github.com/pragsyy1729/cognitive-loop-agent)
An autonomous agent built on an explicit **Memory · Perception · Decision · Action** loop — a from-scratch take on the core agent architecture. Multi-model backbone (each role on a different NVIDIA NIM model), FastAPI LLM gateway with fallback chains, and a 9-tool MCP server.
`NVIDIA NIM` · `MCP` · `FastAPI`

### [Browser Agent](https://github.com/pragsyy1729/browser-agent)
A tool-using agent that **autonomously drives a web browser** to complete tasks — perceives page state, plans a sequence of actions, and loops on feedback until the goal is met. Growing-graph orchestrator (NetworkX) with a 4-layer perception cascade (HTTP → Playwright → accessibility tree → Set-of-Marks vision) and FAISS memory.
`Playwright` · `FAISS` · `NetworkX`

### [SmolLM2-135M — transformer pre-trained from scratch](https://github.com/pragsyy1729/SmolLM135-Retrained-with-suits) · [HF Demo](https://huggingface.co/spaces/pragsyy1729/SmolLM2-135M-from-scratch)
A 135M-parameter Llama-style transformer built end to end in PyTorch — **RoPE, GQA, SwiGLU, RMSNorm**; bf16, Flash Attention, cosine LR. The depth under the agents I build.
`PyTorch` · `RoPE` · `GQA` · `Flash Attention`

### [Technical Assistant](https://github.com/pragsyy1729/technical-assistant)
"Agent7" — a 5-layer agentic pipeline with FAISS retrieval and 11 MCP tools, indexing a research corpus of agentic-systems papers to answer technical questions.
`MCP` · `FAISS` · `RAG`

### [Bookstagram](https://github.com/pragsyy1729/bookstagram) · [Connectopedia](https://github.com/pragsyy1729/connectopedia)
